# specs/draft/README.md

# ⚠️ Draft specifications — NOT the current protocol

These documents describe the pre-0.6 architecture (server-issued
sessions, registry-based key lookup). They are preserved as working
drafts and are **incompatible with @me2em/core 0.6.0**.

The core draft was archived to [`specs/archive/draft-core.md`](../archive/draft-core.md)
(deprecated 2026-10-31). Its placeholder test vectors were replaced by the
real [`specs/test-vectors.json`](../test-vectors.json).

For the current normative protocol see:
- **[`specs/v1.0.md`](../v1.0.md)** — normative specification (v1.0 program)
- [`specs/test-vectors.json`](../test-vectors.json) — conformance vectors
- packages/core/README.md (behavior contract)
- packages/core/USE_CASES.md (flows)
- docs.me2em.com (API reference)

Still open in the backlog: the OpenAPI reference server spec
(BL-22, with `@me2em/server`).
